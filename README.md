# Runā latviski

WordPress theme for [runalatviski.latvijai.lv](https://runalatviski.latvijai.lv).

## Install
Zip the repository contents inside a folder named `runalatviski` and upload via Appearance → Themes → Add New → Upload, or clone into `wp-content/themes/runalatviski`.

## Setup
Customize → "Kampaņa un ziedošana": campaign bar, donate link, social links. Assign menus to *Galvenā izvēlne* and *Kājenes izvēlne*.
